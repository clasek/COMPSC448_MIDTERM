# Report

This folder contains the final project report required for submission.

## Required File

- `project_report.pdf` — final report with team member names and project findings.

## Recommended Report Sections

1. Introduction and motivation
2. Research questions
3. Dataset collection and documentation
4. Data preprocessing
5. CNN implementation
6. RNN/LSTM implementation
7. Experimental setup
8. Results and visualizations
9. Analysis of RQ1 and RQ2
10. Limitations and potential sources of bias
11. Lessons learned
12. References

## Research Questions

The required questions are:

- Can a classifier identify which LLM generated a response?
- Does including the user's prompt improve LLM identification?

Optional sections may investigate whether LLM fingerprints generalize across tasks or which linguistic and structural characteristics distinguish models.
